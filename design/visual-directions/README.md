## Provenance and boundaries

- The Sophie artwork in each comp is derived **only** from [`nownest/assets/sophie-nest.svg`](../../nownest/assets/sophie-nest.svg), an existing original asset in this site repository. `sophie-reference.png` is a raster conversion of that SVG for the comp renderer. It is labeled “Original illustration” and **not** shown as app UI. Sam/Tom should confirm the asset's rights record before public rollout of any changed use.
- Mews & Woofs appears as a typographic **concept preview** card, with “beta not open” beside its name. No pet photography, sample app UI, or claim of working audio processing is introduced.
- Rung uses the exact current retirement wording from [Foculoom's claims-register draft](https://github.com/foculoom/foculoomllc/pull/33). It is an archive record with no active source, install, release, support, or payment CTA.
- NowNest retains its warm product palette and explicit **in qualification / no public download** label. It is not presented as released or accepted by Apple.
- “Edoworks” remains text only; these comps propose no new logo, trademark, favicon, or public lockup.

## Review questions and gates

Sam and Tom should independently score both directions against the supplied visual identity PRD packet for hierarchy, identity coherence, authenticity, legibility, finish, and trust. Cite the exact canvas/detail for each score. Record accept/revise/reject for the direction, and identify the source and owner for every factual objection.

The proposed source implementation may use Direction A as a reversible branch preview because its calm editorial frame gives NowNest and Mews distinct visual space and keeps Rung historical. **No direction is approved for publication yet.** The paired Foculoom/Edoworks blind comprehension review, exact-build browser captures, 400% reflow, contrast, keyboard, reduced-motion, and public link checks remain release gates.

The PNGs were generated by `render_comps.py` with Pillow using actual proposed copy and the existing Sophie asset. They are intentionally static: a comp that looks correct does not prove that the HTML/CSS build behaves correctly.

Tom's mobile review led to a revision of Direction A: the home and portfolio place NowNest's status, name, purpose, and qualification link before the decorative Sophie art at widths of 700 CSS pixels or less. The concept and archive cards use one status pill each, without duplicate title bands. The 390-pixel Direction A PNGs show that revised reading hierarchy; the 1280-pixel PNGs retain the desktop art placement. Direction A's PNGs now include the proposed site's NowNest navigation, qualification copy, status copy, text links, and homepage process note. These remain compositions, not browser captures.

**Pixel-equivalence gate — NOT RUN.** The renderer uses fixed image canvases and approximates spacing and typography; the compact footer omits some live HTML links and the build stamp. Direction B remains a visual alternative without an HTML implementation, and some of its supporting text is abbreviated. Reviewers should judge layout intent from the PNGs and judge actual content and responsive behavior only from an exact-branch browser render when that gate can run.
