Dated history

Edoworks documented version 0.3.1 on August 26, 2026 and version 0.3.2 on September 15, 2026. Those dated articles describe the release state at the time; Rung was later retired.

Read the 0.3.1 historical note · Read the 0.3.2 historical note

What the engine examined

  • Scored repository governance evidence across six maturity states.
  • Reported a conservative maximum recommended agent authority.
  • Produced deterministic JSON, text, receipt, and replay evidence.
  • Served as an assessment aid, not certification, compliance advice, or release approval.
