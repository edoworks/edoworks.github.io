Privacy Policy

Last updated: August 7, 2026

Overview

Edoworks.com is a static website hosted on GitHub Pages. We do not collect, store, or process any personal data from visitors to this site.

What we do not collect

Edoworks.com does not use:

  • Analytics: No Google Analytics, no Plausible, no Fathom, no self-hosted analytics of any kind.
  • Cookies: No tracking cookies, no session cookies, no functional cookies.
  • Third-party trackers: No advertising trackers, no social trackers, no fingerprinting scripts.
  • Forms: No forms that collect personal information are present on this site.
  • Account systems: No accounts, no logins, no user data.

First-party services

Blog posts on edoworks.com include a lightweight upvote widget operated by Foculoom LLC (our parent company) on the foculoom.com domain. When you click the upvote button on a blog post, the widget sends the post's URL slug and your upvote count to a Foculoom-operated Cloudflare Worker endpoint. This service does not use cookies, does not collect personal data, does not track you across pages, and does not fingerprint your browser. The only data sent is the blog post identifier and the upvote action. This is a first-party Foculoom service, not a third-party tracker.

Hosting

This website is hosted on GitHub Pages. GitHub may retain standard web server access logs (IP address, browser user-agent, requested URL) in accordance with their own data retention policies. We do not control or have access to these logs. See GitHub's Privacy Statement for details.

Contact

If you have questions about this privacy policy, contact us at support@foculoom.com.

Changes

If this policy changes, we will update the "Last updated" date above and republish this page.
