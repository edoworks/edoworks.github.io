# edoworks.github.io

Public website for **Edoworks** — a software factory.

- **Domain:** `edoworks.com` (pending registration, FG-114 — founder
  approval gate. See
  `.factory/reports/2026-07-21-edoworks-brand-infrastructure-5-whys.md`.)
- **Surfaces:** landing (`index.html`), blog (`blog/index.html`), portfolio
  (generated by `make portfolio` from
  `.factory/config/product-registry.json` into `docs/portfolio/index.html`
  in the factory repo, then published here).
- **Factory stamp:** every HTML page carries
  `<meta name="generator" content="Edoworks <version>">` and a
  `Built by Edoworks <version>.` footer per
  `.factory/standards/factory-stamp.md`.

## Brand architecture

- **Edoworks** = software factory (stamp + portfolio + blog at `edoworks.com`).
- **Foculoom LLC** = legal entity (corporate site at `foculoom.com`).

See `.factory/standards/factory-stamp.md` § Brand architecture.
