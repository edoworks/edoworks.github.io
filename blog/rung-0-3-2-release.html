Rung 0.3.2: Canonical Edoworks Distribution

Edoworks - September 15, 2026

Rung 0.3.2 makes the verified Edoworks project page the public discovery surface and clarifies the free artifact contract.

Available artifacts

Rung is available as a free MIT-licensed Python package and dependency-free standalone CLI. The release artifacts do not require Docker, an account, or network access to the repository being audited.

  • GitHub release v0.3.2
  • PyPI package v0.3.2
  • Source repository

What changed

  • Public discovery moved to the verified Edoworks Rung project page.
  • Release-path checks make the container-free artifact contract explicit.
  • Wheel, source distribution, and standalone artifact validation remain reproducible.

Limits

Rung is an assessment aid, not certification, compliance advice, enforcement proof, or release approval. Public availability does not establish adoption, customers, revenue, or commercial operation.

The former rung.edoworks.com origin is not required by the artifacts and remains a separate hosting/deprecation task.
