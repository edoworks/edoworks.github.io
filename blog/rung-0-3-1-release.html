Scope and limitations

Rung inspected observable repository evidence. It did not execute code from the repository being audited. Controls that could not be observed from public evidence were marked unobservable rather than guessed.

Rung was an assessment aid, not certification, compliance advice, an enforcement mechanism, or authority to approve a release. Publication at the time did not establish indexing, usage, customers, revenue, or adoption; it does not establish availability today.
