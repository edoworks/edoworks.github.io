Rung 0.3.1 Is Available

Edoworks - August 26, 2026

The free MIT-licensed repository governance-evidence CLI is published on GitHub and PyPI.

Install the exact release

python3 -m pip install "rung-audit==0.3.1"

The release is available from the immutable GitHub Release and the PyPI project. Both channels expose version 0.3.1 wheel and source artifacts.

What was verified

  • Tests passed across supported Python versions on Linux, macOS, and Windows.
  • The package was built twice and compared for reproducibility.
  • The built wheel was installed and exercised in a clean environment.
  • The modular package and standalone CLI produced matching results.
  • GitHub recorded build provenance before the release and PyPI publication jobs completed.

The complete job record is public in GitHub Actions run 32918286709.

Scope and limitations

Rung inspects observable repository evidence. It does not execute code from the repository being audited. Controls that cannot be observed from public evidence remain unobservable rather than being guessed.

Rung is an assessment aid. It is not certification, compliance advice, an enforcement mechanism, or authority to approve a release. Publication establishes availability only; it does not establish indexing, usage, customers, revenue, or adoption.
