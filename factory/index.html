Factory Dashboard

Edoworks is a one-person software studio that builds apps using an AI-assisted factory — a set of AI agents that research, plan, build, test, and review software. This page shows, in public, how that factory is running right now.

Each card below is a live measurement. Green means a check is passing; the numbers are real data from the last few weeks, not estimates. The page regenerates itself automatically and is published as-is — no manual editing.

What the terms mean
Autonomy ratio
How many hours of productive work the AI agents did for each hour of human time. Higher means the factory ran more autonomously that day.
Factory cost
What the cloud and AI tools cost the factory per day, in US dollars.
Recurring operating cost
The fixed monthly subscriptions the factory pays (AI tools, cloud, code hosting). The annual figure is what those subscriptions cost over a year.
Operating capacity
A model of how much AI-compute headroom the subscriptions give the factory. Upgrading a cheaper plan to a larger one multiplies that headroom.
Provenance: measured
The number was actually observed from a real source (a billing API or a log file), not estimated or guessed.
